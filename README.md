### 🎥 [Brand Guardian AI — Video Content Compliance Auditor](https://github.com/BlueGod01/AI-YT_Video-Content-Compliance-Auditing-Pipeline)
**Agentic AI Pipeline · Azure · LangGraph · FastAPI**

> *What if you could automatically audit every video for regulatory compliance before it goes live?*

Built a production-grade AI system that ingests YouTube videos, extracts transcripts and visual metadata via Azure Video Indexer, and checks content against FTC rules and advertising platform policies — all without a human reviewer in the loop.

The system uses a **LangGraph DAG** to orchestrate a multi-stage pipeline: ingestion → transcription → policy retrieval from Azure AI Search → contextual reasoning via Azure OpenAI → violation categorization by severity → structured compliance report generation.

Fully containerized with Docker, deployed on Azure, and instrumented with LangSmith + OpenTelemetry for end-to-end tracing. This isn't a chatbot — it's an autonomous compliance workflow.

**Stack:** Python · FastAPI · LangChain · LangGraph · Azure OpenAI · Azure AI Search · Azure Video Indexer · PostgreSQL · Redis · Streamlit · Docker · OpenTelemetry · LangSmith

### 📚 [Multimodal Agentic Research Assistant & Report Builder](https://github.com/BlueGod01/MultiModal_Research_Assistant_-_Report_Builder)
**Multi-Agent System · LangGraph · Pinecone · AWS S3**

> *Deep research that used to take days — done in minutes.*

An advanced agentic system where users can have a conversation with multiple books and knowledge sources simultaneously. The system parses and chunks PDFs using `docling`, embeds and stores them in Pinecone, and retrieves only the most semantically relevant passages during queries.

Under the hood, a **LangGraph orchestrator** coordinates a Q&A Research Agent, distributed worker agents, and a reducer that synthesizes outputs into structured answers. When internal knowledge isn't enough, the system automatically performs live web search to fill the gap.

Conversations persist across sessions via SQLite checkpointing. Users can also export the entire research thread as a clean, formatted PDF report — transforming months of manual research into hours.

**Stack:** Python · FastAPI · LangChain · LangGraph · OpenAI APIs · Pinecone · AWS S3 · Streamlit · docling · reportlab · Docker

### 🏢 [Agentic HR Management System](https://github.com/BlueGod01/Agentic-HR-Management_System)
**Multi-Agent Architecture · LangGraph · PostgreSQL RLS · WhatsApp Integration**

> *An HR team that's always available — and always secure.*

A production-grade HR platform where employees can query their own leave, payroll, and policy data through a conversational interface — without ever waiting for an HR team member to respond.

Security is built into every layer: a SQL agent with read-only, row-level security access ensures employees only ever see their own data. A RAG-based policy auditing agent answers HR policy questions from a curated knowledge base. An email agent drafts responses — but every email requires **employer approval before it's sent** (human-in-the-loop by design).

Employers manage operations and receive real-time alerts via **WhatsApp**, making this genuinely operational for business use.

**Stack:** FastAPI · LangGraph · Gemini (Google LLMs) · PostgreSQL (RLS) · Redis · Celery · FAISS / Pinecone · Green API (WhatsApp) · SMTP · Docker

### 🏥 [Smart SLM Medical Assistant](https://github.com/BlueGod01/Medical-Bot-Fine-tuned-and-GRPO-trained-)
**SLM Fine-Tuning · GRPO RLHF · RAG · Llama 3.2**

> *A medical reasoning model that thinks before it answers.*

Rather than prompting a large general-purpose model, I built a specialized medical assistant by fine-tuning **Llama 3.2 (SLM)** on complex clinical reasoning datasets using **SFT** and **GRPO RLHF** — a reinforcement learning approach that improves logical consistency without needing a separate critic model.

The model is grounded with a dual-source RAG pipeline: a static FAISS index of authoritative medical literature combined with real-time web search via Tavily. This significantly reduces hallucinations and ensures responses are evidence-backed.

This project demonstrates that a well-trained small model — cheaper to run, faster to serve — can outperform a bloated general-purpose one in a specific domain.

**Stack:** Llama 3.2 · SFT · GRPO RLHF · RAG · Tavily Web Search · FAISS · LangChain · PyTorch · HuggingFace Transformers · PEFT (LoRA) · BitsAndBytes
